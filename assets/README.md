# assets/ (local only)

This folder is **git-ignored** except for this file.

Put everything you extract or convert here: KH2 models from OpenKh, Witcher 3
meshes exported from REDkit, Blender working files, textures. None of it is
committed, because the models belong to Square Enix and CD PROJEKT RED.

Suggested layout:

```
assets/
  kh2_extract/      raw OpenKh output (.mdlx, textures)
  kh2_converted/    FBX/DAE exported from OpenKh
  w3_reference/     Geralt skeleton/body exported from REDkit
  blender/          .blend working files
  export/           final FBX files ready to import into REDkit
```
